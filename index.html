▣ Learning Center

How to compress an image

  1. Open Image Tools → Compress.
  2. Select your image from your device.
  3. Choose a quality level and optional maximum width.
  4. Press Process Image, then download the result.

How to edit an image background manually

  1. Open Image Tools → Manual Background Editor.
  2. Upload an image and choose Erase Brush.
  3. Paint over areas you want to make transparent.
  4. Use Restore Brush and Undo/Redo to correct edits.
  5. Optionally add a color or background image, then download PNG or JPG.

How to create a QR code

  1. Open QR Code Generator.
  2. Enter text or a full website address.
  3. Choose a size and generate the code.
  4. Download the PNG and test it with your phone camera.

Keep your files private

Image and text tools work inside your browser. Avoid using public or shared devices for private files, and close the tab when finished.

PDF tips

Use page numbers such as 1,3,5-7 to extract selected pages. When merging, choose files in the order you want them combined.
